# Lord of the Rings – Next.js Exercise

This is a simple exercise project for the Advanced Web Development course at Spiced Academy (AWD25), built to practice basic Next.js App Router features.

The app lists Lord of the Rings volumes and their books using static data, with dynamic routes and custom error pages.

## Key Features

- Next.js App Router: Pages and dynamic routes for volumes
- Static Data: All info from `lib/data.ts`
- Custom 404 Pages: Basic not-found handling
- Tailwind CSS: Simple styling

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
